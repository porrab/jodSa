# Mobile UX corrections — 2026-11-18

## FB-1 — Header Add on inactive holdings tab

**Summary:** Add Holding worked only while Holdings was mounted. The add sheet and
its state now belong to `InvestTabs`, which remains mounted across all three tabs.

**Root cause:** the header dispatched `jodsa:holding-add`, but its only listener
lived in `InvestClient`. Changing tabs unmounted the listener. Holdings-only tests
missed the lifetime mismatch. Source tracing ruled out a disabled button or overlay.

**Fix:** replace the window event with parent state and render `AddHoldingSheet`
beside the page tabs. The existing form, custom-asset flow and server action remain.

**Validation:** `ux-mobile-audit.spec.ts` failed on the pre-fix production bundle
(dialog absent on Overview, 15s assertion); after rebuild, the same test passed
for Holdings, Overview and Plan (1/1). Build passed. Full round gates follow below.
